# Module 2 – Analytics and Machine Learning

This module performs exploratory data analysis, preprocessing,
machine learning model training, evaluation, and visualization
using the Titanic dataset.

## Files

- `01_eda.py` – Exploratory data analysis and visualizations
- `02_modeling.py` – Data preprocessing, model training and evaluation
- `titanic.csv` – Dataset used for analysis and modeling
- `best_titanic_pipeline.joblib` – Saved best-performing ML pipeline

## Models

- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation

The models are evaluated using:

- Accuracy
- Confusion Matrix
- ROC-AUC
- ROC Curve comparison

## Visualizations

The module includes EDA charts, confusion matrices,
decision tree visualization, regression residuals,
and ROC comparison plots.
